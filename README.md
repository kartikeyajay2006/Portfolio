## Why it's still here

This is where I started: no framework, no build step, just semantic HTML, CSS and links between pages.
Comparing it with my [current portfolio](https://github.com/kartikeyajay2006/kartikeya-portfolio) and with projects such as [JKY Terminal](https://github.com/kartikeyajay2006/jky-terminal) shows how far things have come.

## Run it

No build step is needed. Open `index.html` in any browser.
